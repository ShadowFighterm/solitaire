# 🃏 Solitaire Game (C# with MonoGame)

A classic **Solitaire (Klondike)** card game built using **C# and the MonoGame framework**.  
This project demonstrates concepts such as game loops, card rendering, input handling (drag-and-drop), rules enforcement, and scoring.  

---

## 🚀 Features
- Classic **Klondike Solitaire** rules  
- Card shuffling and dealing  
- Drag and drop mechanics for cards  
- Valid move detection  
- Stock, waste, foundation, and tableau piles  
- Restart / New Game option  
- Scoring system  

---

## 🔧 Prerequisites
Before running the game, make sure you have the following installed:

- **.NET 6.0+ SDK** → [Download .NET](https://dotnet.microsoft.com/download)  
- **MonoGame Framework** → [MonoGame Downloads](https://www.monogame.net/downloads/)  
- **Git**
